# Amazon USA Sales Analysis Project

## Project Overview
This project focuses on analyzing sales data for Amazon USA using advanced SQL techniques. It involves designing a normalized relational database schema (comprising tables for customers, orders, products, sellers, inventory, shipping, and payments) to accurately represent e-commerce operations. The project aims to process and analyze large datasets to uncover actionable business insights regarding sales trends, customer behavior, and operational efficiency.

## Objective
The main objective is to utilize complex SQL queries to solve real-world business problems and extract meaningful insights from the sales data. This includes analyzing product performance, tracking shipping and delivery metrics, evaluating seller contributions, and understanding customer purchasing patterns to support data-driven decision-making.
